# Contributing to L

Thank you for your interest in L!

## Current Stage

L is in the **early design** phase. The most valuable contributions right now are:

1. **Feedback on language design**
   - Is the Kotlin baseline the right choice?
   - What Minecraft modding pain points should the language solve?
   - What do launcher developers (especially Android Java Edition launchers) need?

2. **Use-case descriptions**
   - Real mod or launcher scenarios that are painful today
   - Desired DSLs or APIs

3. **Specification improvements**
   - Clarifications
   - Missing features
   - Edge cases

4. **Documentation**
   - Better explanations
   - More examples

## How to Contribute

- Open a GitHub Issue for discussion
- Open a Pull Request for documentation or specification changes
- Keep discussions focused and constructive

## Code of Conduct

Be respectful. We are building something ambitious — collaboration works best when people feel safe to share ideas.
